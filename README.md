# Sail Status

Public status page for Sail: **https://status.savewithsail.com**

Powered by [Upptime](https://upptime.js.org): GitHub Actions checks each component every 5 minutes, GitHub Issues hold incidents, and GitHub Pages serves the site. Configuration lives in [`.upptimerc.yml`](.upptimerc.yml); the Upptime workflows in `.github/workflows` are generated from it.

To post an incident or maintenance window, follow [docs/incident-communication.md](docs/incident-communication.md).
